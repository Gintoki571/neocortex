# Knowledge organization (indexing, KG construction, hybrid)

* [E^2GraphRAG: Streamlining Graph-based RAG for High Efficiency and Effectiveness](e2graphrag.md) - GraphRAG variant that builds the entity graph with SpaCy (no LLM) plus a summary tree, bidirectional entity-chunk indexes, and adaptive local/global retrieval with no LLM calls at query time. (neocortex: adopt · LLM: indexing)
* [LinearRAG: Linear Graph Retrieval Augmented Generation on Large-scale Corpora](linearrag.md) - Relation-free Tri-graph of entities, sentences and passages, built with spaCy NER, plus two-stage entity activation and PPR passage ranking; zero LLM tokens for indexing and retrieval. (neocortex: adopt · LLM: none)
* [AGRAG: Advanced Graph-based Retrieval-Augmented Generation for LLMs](agrag.md) - Builds a statistics-based graph and retrieves an explicit Minimum Cost Maximum Influence subgraph as reasoning paths for the LLM. (neocortex: adapt · LLM: both)
* [KET-RAG: A Cost-Efficient Multi-Granular Indexing Framework for Graph-RAG](ket-rag.md) - Graph-RAG index with a small LLM-built knowledge-graph skeleton from PageRank-selected chunks plus a cheap text-keyword bipartite graph, to cut indexing cost. (neocortex: adapt · LLM: indexing)
* [Knowledge Graph Prompting for Multi-Document Question Answering](knowledge-graph-prompting.md) - Builds a passage and structure graph over several documents, then uses an LLM-guided traversal agent to select the prompt context. (neocortex: adapt · LLM: both)
* [OG-RAG: Ontology-Grounded Retrieval-Augmented Generation For Large Language Models](og-rag.md) - Builds a hypergraph of domain documents whose hyperedges are grounded in an ontology, then retrieves the minimal hyperedge set covering a query. (neocortex: adapt · LLM: retrieval)
* [Answering complex questions by joining multi-document evidence with quasi knowledge graphs](quasi-kg-multi-doc-qa.md) - Joins evidence across documents through a quasi-KG (SIGIR 2019). (neocortex: watch · LLM: none)
* [ArchRAG: Attributed Community-based Hierarchical Retrieval-Augmented Generation](archrag.md) - Community-based hierarchical GraphRAG that augments queries with attributed communities and uses LLM-based hierarchical clustering. (neocortex: watch · LLM: both)
* [AutoKG: Efficient Automated Knowledge Graph Generation for Language Models](autokg.md) - Automated KG generation for language models (BigData 2023). (neocortex: watch · LLM: both)
* [Biomedical knowledge graph-enhanced prompt generation for large language models](biomedical-kg-prompt-generation.md) - KG-RAG retrieves a compact, embedding-pruned slice of the SPOKE biomedical knowledge graph and places it in the prompt, cutting token use by about half versus a Cypher-schema baseline (Bioinformatics 2024). (neocortex: watch · LLM: both)
* [Context-Aware Fine-Grained Graph RAG for Query-Focused Summarization](context-aware-fine-grained-graph-rag.md) - FG-RAG adds context-aware entity expansion to graph retrieval and query-level fine-grained summarisation at generation time, for query-focused summarisation (CIKM 2025 short paper). (neocortex: watch · LLM: both)
* [DBCopilot: Natural Language Querying over Massive Databases via Schema Routing](dbcopilot.md) - A compact copilot model routes a question to the right database schema before SQL generation, decoupling routing from NL2SQL. (neocortex: watch · LLM: both)
* [Detecting Hallucinations in Graph Retrieval-Augmented Generation via Attention Patterns and Semantic Alignment](hallucination-detection-graphrag.md) - Two lightweight interpretability metrics (path reliance and semantic alignment) to flag hallucinations in GraphRAG generation. (neocortex: watch · LLM: both)
* [DynaGRAG: Dynamic Graph Retrieval-Augmented Generation](dynagrag.md) - Graph RAG that de-duplicates and densifies the knowledge graph, then retrieves diverse subgraphs with a Dynamic Similarity-Aware BFS. (neocortex: watch · LLM: both)
* [Empowering Large Language Models to Set up a Knowledge Retrieval Indexer via Self-Learning](pg-rag.md) - PG-RAG: an LLM writes concise notes from raw text, which form a pseudo-graph index; retrieval follows the most corroborated fact paths. (neocortex: watch · LLM: indexing)
* [FastRAG: Retrieval Augmented Generation for Semi-structured Data](fastrag.md) - Schema and script learning extract structure from semi-structured network data, then text search and KG querying answer questions. (neocortex: watch · LLM: both)
* [From Local to Global: A Graph RAG Approach to Query-Focused Summarization](graphrag-local-to-global.md) - Microsoft GraphRAG: an LLM builds an entity knowledge graph and hierarchical community summaries, answering global questions by map-reduce over the summaries. (neocortex: watch · LLM: both)
* [G-reasoner: Foundation Models for Unified Reasoning over Graph-structured Knowledge](g-reasoner.md) - A graph foundation model that reasons over graph-structured knowledge in a unified way for RAG. (neocortex: watch · LLM: retrieval)
* [Graph of Records: Boosting Retrieval Augmented Generation for Long-context Summarization with Graphs](graph-of-records.md) - Links retrieved text chunks to the LLM responses that used them, then trains a GNN with a BERTScore-based objective to retrieve for global summarisation. (neocortex: watch · LLM: both)
* [GraphReader: Building Graph-based Agent to Enhance Long-Context Abilities of Large Language Models](graphreader.md) - An LLM agent that structures a long text into a graph and explores it with read-node and neighbour functions. (neocortex: watch · LLM: both)
* [KAG: Boosting LLMs in Professional Domains via Knowledge Augmented Generation](kag.md) - Professional-domain framework that mutually indexes KGs and text chunks and uses logical-form-guided reasoning. (neocortex: watch · LLM: both)
* [LEGO-GraphRAG: Modularizing Graph-based Retrieval-Augmented Generation for Design Space Exploration](lego-graphrag.md) - Decomposes GraphRAG into modular steps, classifies existing methods, and reports empirical quality, runtime and cost trade-offs. (neocortex: watch · LLM: both)
* [MaGiX: A Multi-Granular Adaptive Graph Intelligence Framework for Enhancing Cross-Lingual RAG](magix.md) - Multi-granular graph RAG for cross-lingual retrieval (EMNLP 2025 Findings). (neocortex: watch · LLM: both)
* [Ontology Learning and Knowledge Graph Construction: A Comparison of Approaches and Their Impact on RAG Performance](ontology-learning-kg-comparison.md) - Compares vector RAG, GraphRAG and KGs built from ontologies derived from relational databases or text. (neocortex: watch · LLM: indexing)
* [Retrieval-Augmented Generation with Hierarchical Knowledge](hirag.md) - HiRAG: hierarchical knowledge indexing and retrieval for domain-specific RAG. (neocortex: watch · LLM: indexing)
* [Retrieval-augmented generation with knowledge graphs for customer service question answering](kg-customer-service-rag.md) - KG-augmented RAG for customer service (SIGIR 2024). (neocortex: watch · LLM: both)
* [Simple is Effective: The Roles of Graphs and Large Language Models in Knowledge-Graph-Based Retrieval-Augmented Generation](simple-is-effective-kg-rag.md) - Analysis of the roles of graphs and LLMs in KG-based RAG (ICLR 2025). (neocortex: watch · LLM: both)
* [SUBQRAG: Sub-Question Driven Dynamic Graph RAG](subqrag.md) - Decomposes a question into ordered sub-questions and expands the KG on the fly from source documents when triples are missing. (neocortex: watch · LLM: both)
* [Using Local Knowledge Graph Construction to Scale Seq2Seq Models to Multi-Document Inputs](local-kg-seq2seq.md) - Local KG construction to feed multi-document inputs to seq2seq models (ACL 2019). (neocortex: watch · LLM: none)
* [You Don't Need Pre-built Graphs for RAG: Retrieval Augmented Generation with Adaptive Reasoning Structures](no-prebuilt-graph-rag.md) - Builds the reasoning structure per query at retrieval time instead of pre-constructing a corpus graph, to avoid token cost and update latency. (neocortex: watch · LLM: both)
* [Youtu-GraphRAG: Vertically Unified Agents for Graph Retrieval-Augmented Complex Reasoning](youtu-graphrag.md) - Agentic GraphRAG that couples a seed graph schema (entity, relation and attribute types) with graph construction and retrieval. (neocortex: watch · LLM: both)
* [Agentic-KGR: Co-evolutionary Knowledge Graph Construction through Multi-Agent Reinforcement Learning](agentic-kgr.md) - Co-evolves an LLM and a KG through multi-round RL with dynamic schema expansion and a retrieval-augmented memory. (neocortex: skip · LLM: both)
* [AutoGraph-R1: End-to-End Reinforcement Learning for Knowledge Graph Construction](autograph-r1.md) - Trains an LLM KG constructor with RL, using the downstream RAG utility as the reward. (neocortex: skip · LLM: indexing)
* [AVIS: Autonomous Visual Information Seeking with Large Language Model Agent](avis.md) - LLM agent that plans tool calls and reads their outputs to answer visual questions needing external knowledge. (neocortex: skip · LLM: both)
* [CodexGraph: Bridging Large Language Models and Code Repositories via Code Graph Databases](codexgraph.md) - LLM agent that writes graph-database queries against a code graph for repository-scale navigation. (neocortex: skip · LLM: both)
* [DocPolicyKG: A Lightweight LLM-Based Framework for Knowledge Graph Construction from Chinese Policy Documents](docpolicykg.md) - Builds a knowledge graph from Chinese investment-promotion policy documents with a fine-tuned 7B-class LLM plus ontology and prompting, then adds Graph RAG for policy QA (CIKM 2025; abstract only). (neocortex: skip · LLM: indexing)
* [GraphCoder: Enhancing Repository-Level Code Completion via Code Context Graph-based Retrieval and Language Model](graphcoder.md) - Code completion with a code context graph (control, data and dependence edges) and a coarse-to-fine graph retrieval. (neocortex: skip · LLM: both)
* [Grounded by Experience: Generative Healthcare Prediction Augmented with Hierarchical Agentic Retrieval](grounded-by-experience.md) - Healthcare prediction with hierarchical agentic retrieval that decides when retrieval is clinically necessary. (neocortex: skip · LLM: both)
* [KNOWNET: Guided Health Information Seeking from LLMs via Knowledge Graph Integration](knownet.md) - Visualisation system that maps LLM-output triples to KG evidence and recommends next exploration steps. (neocortex: skip · LLM: both)
* [LuminiRAG: Vision-Enhanced Graph RAG for Complex Multi-Modal Document Understanding](luminirag.md) - Single-author TechRxiv preprint, a graph RAG for multi-modal documents that adds vision-language extraction and cross-modal graph links (abstract only). (neocortex: skip · LLM: both)
* [Medical Graph RAG: Towards Safe Medical Large Language Model via Graph Retrieval-Augmented Generation](medical-graph-rag.md) - Medical GraphRAG with triple graph construction linking documents to medical sources and controlled vocabularies, and U-Retrieval. (neocortex: skip · LLM: both)
* [MedRAG: Enhancing Retrieval-augmented Generation with Knowledge Graph-Elicited Reasoning for Healthcare Copilot](medrag.md) - Medical RAG with a four-tier hierarchical diagnostic KG that separates confusable diseases. (neocortex: skip · LLM: both)
* [PersonaAgent with GraphRAG: Community-Aware Knowledge Graphs for Personalized LLM](persona-agent-graphrag.md) - Persona agent using an LLM-derived graph index with community summaries to build personalised prompts. (neocortex: skip · LLM: both)
* [PIKE-RAG: sPecIalized KnowledgE and Rationale Augmented Generation](pike-rag.md) - Industrial RAG that extracts domain knowledge and builds rationale chains to steer LLM answers. (neocortex: skip · LLM: both)
* [ProLLM: Protein Chain-of-Thoughts Enhanced LLM for Protein-Protein Interaction Prediction](prollm.md) - Protein-interaction prediction with KG-based chain-of-thought (CoLM 2024). (neocortex: skip · LLM: both)
* [SayPlan: Grounding Large Language Models using 3D Scene Graphs for Scalable Robot Task Planning](sayplan.md) - Robot task planning where an LLM does semantic search over a collapsed 3D scene graph, then plans with a classical path planner. (neocortex: skip · LLM: both)
* [Structure Guided Prompt: Instructing Large Language Model in Multi-Step Reasoning by Exploring Graph Structure of the Text](structure-guided-prompt.md) - Prompting that represents the text as a graph and guides an LLM through multi-step reasoning along it. (neocortex: skip · LLM: both)
