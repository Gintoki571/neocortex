# Knowledge integration (fine-tuning, in-context learning)

* [KnowledGPT: Enhancing Large Language Models with Retrieval and Storage Access on Knowledge Bases](knowgpt.md) - Program-based retrieval over public KBs plus a personalized KB that the LLM fills from documents; not the same work as KnowGPT (arXiv 2312.06185). (neocortex: adapt · LLM: both)
* [Mitigating Large Language Model Hallucinations via Autonomous Knowledge Graph-based Retrofitting](kg-retrofitting-hallucination.md) - KGR checks an LLM draft's claims against KG facts, selects and verifies them, and retrofits the draft during reasoning. (neocortex: adapt · LLM: both)
* [Plan-on-Graph: Self-Correcting Adaptive Planning of Large Language Model on Knowledge Graphs](plan-on-graph.md) - PoG decomposes a question into sub-objectives, explores KG paths adaptively, updates memory, and self-corrects by reflection. (neocortex: adapt · LLM: both)
* [Reasoning on Graphs: Faithful and Interpretable Large Language Model Reasoning](reasoning-on-graphs.md) - RoG plans relation paths with an LLM, then retrieves faithful reasoning paths from the KG and answers from them. (neocortex: adapt · LLM: retrieval)
* [Think-on-Graph 2.0: Deep and Faithful Large Language Model Reasoning with Knowledge-guided Retrieval Augmented Generation](think-on-graph-2.md) - Training-free hybrid RAG that iterates between text passages and a KG, linking documents through entities, in a tight-coupling loop. (neocortex: adapt · LLM: both)
* [Think-on-Graph: Deep and Responsible Reasoning of Large Language Model on Knowledge Graph](think-on-graph.md) - LLM-guided beam search over a KG: the LLM explores relations and prunes candidate triples at each hop, with depth D and width N. (neocortex: adapt · LLM: retrieval)
* [CogMG: Collaborative Augmentation Between Large Language Model and Knowledge Graph](cogmg.md) - Agent demo in which an LLM decomposes a question into KG triples, fills the triples missing from the graph, and writes the completions back into the KG (ACL 2024 demo). (neocortex: watch · LLM: both)
* [Different Paths to the Same Destination: Diversifying LLMs Generation for Multi-hop Open-domain Question Answering](diversifying-llm-multihop-paths.md) - DP-CoT: diverse passage- and sentence-level evidence generation, pruned by a BERT-style evidence classifier, for multi-hop open-domain QA (KBS 2025). (neocortex: watch · LLM: both)
* [Dual Reasoning: A GNN-LLM Collaborative Framework for Knowledge Graph Question Answering](explore-then-determine.md) - DualR: a GNN-based explorer on the KG that backtracks reasoning chains, which a frozen LLM reads as a multiple-choice prompt to pick the answer (README name: Explore then Determine). (neocortex: watch · LLM: both)
* [Graph Chain-of-Thought: Augmenting Large Language Models by Reasoning on Graphs](graph-chain-of-thought.md) - Graph-CoT lets an LLM traverse a text-attributed graph step by step (reason, interact, execute) and ships GRBench, 1,740 questions over 10 domain graphs. (neocortex: watch · LLM: both)
* [Graph-oriented Instruction Tuning of Large Language Models for Generic Graph Mining (MuseGraph)](musegraph.md) - MuseGraph: one LLM (LLaMA3-8B default) tuned on compact text graph descriptions with GPT-4 chain-of-thought instruction packages, for node classification, link prediction and graph-to-text across datasets (arXiv 2024). (neocortex: watch · LLM: indexing)
* [Knowledge Graph-Enhanced Large Language Models via Path Selection](kg-enhanced-llm-path-selection.md) - KELP scores KG paths against the input text by latent semantic matching, then feeds the selected paths to the LLM (ACL Findings 2024). (neocortex: watch · LLM: both)
* [LLaGA: Large Language and Graph Assistant](llaga.md) - LLaGA: a Vicuna-7B assistant that turns each node's fixed-size sampled neighbourhood into a template-ordered token sequence (ND and HO templates) and aligns it with a projector, for node classification and link prediction (ICML 2024). (neocortex: watch · LLM: indexing)
* [An Explanation of In-context Learning as Implicit Bayesian Inference](icl-implicit-bayesian-inference.md) - Theory that in-context learning emerges when pretraining documents are mixtures of HMM concepts, so the LM infers a latent concept from the prompt; checked on the synthetic GINC dataset (ICLR 2022). (neocortex: skip · LLM: none)
* [Chain-of-Knowledge: Grounding Large Language Models via Dynamic Knowledge Adapting over Heterogeneous Sources](chain-of-knowledge.md) - Prepares sampled rationales, and only when the answers disagree corrects them step by step from heterogeneous sources (text, Wikidata, tables). (neocortex: skip · LLM: both)
* [Exploring Large Language Model for Graph Data Understanding in Online Job Recommendations](job-recommendation-llm-graph-understanding.md) - GLRec: a BELLE-LLaMA-7B recommender fed with behaviour-graph meta-path prompts and a path-attention augmentation, tuned with LoRA for job matching (AAAI 2024). (neocortex: skip · LLM: indexing)
* [Graph Neural Prompting with Large Language Models](graph-neural-prompting.md) - GNP: a plug-and-play GNN that encodes a retrieved ConceptNet or biomedical KG subgraph into soft prompts for a frozen or LoRA-tuned FLAN-T5 (AAAI 2024). (neocortex: skip · LLM: indexing)
* [GraphGPT: Graph Instruction Tuning for Large Language Models](graphgpt.md) - Fine-tunes a Vicuna-7B LLM with graph instruction tuning (text-graph grounding plus CoT distillation) so one model handles node classification and link prediction across graph datasets. (neocortex: skip · LLM: indexing)
* [GraphWiz: An Instruction-Following Language Model for Graph Computational Problems](graphwiz.md) - GraphInstruct (nine graph problem types with explicit reasoning paths) and GraphWiz, a 7B to 13B LLM tuned on it with DPO; it beats GPT-4 on the average over the test set (KDD 2024). (neocortex: skip · LLM: indexing)
* [Language is All a Graph Needs](language-is-all-a-graph-needs.md) - InstructGLM: a generative LLM (Flan-T5 or LoRA-tuned LLaMA) instruction-tuned on text serialisations of citation graphs for node classification, with a link-prediction auxiliary task (EACL 2024 Findings). (neocortex: skip · LLM: indexing)
* [Large Language Models based Graph Convolution for Text-Attributed Networks?](llm-graph-convolution-text-attributed-networks.md) - LLM-based graph convolution on text-attributed networks (OpenReview forum x5FfUvsLIE). Title and authors matched; no abstract or paper text was retrievable. (neocortex: skip · LLM: indexing)
* [Plan-and-Solve Prompting: Improving Zero-Shot Chain-of-Thought Reasoning by Large Language Models](plan-and-solve-prompting.md) - PS and PS+ zero-shot prompts: first plan the subtasks, then solve with explicit variable and calculation instructions; they beat Zero-shot-CoT on arithmetic and commonsense reasoning (ACL 2023). (neocortex: skip · LLM: both)
* [RHO (ρ): Reducing Hallucination in Open-domain Dialogues with Knowledge Grounding](rho-hallucination-dialogue.md) - RHO grounds a dialogue response in linked KG entities and relation predicates (local and global knowledge grounding) and re-ranks candidates, tested on OpenDialKG (ACL Findings 2023). (neocortex: skip · LLM: both)
* [Structure Pretraining and Prompt Tuning for Knowledge Graph Transfer](kg-transfer-structure-pretraining-prompt-tuning.md) - KGTransformer: a transformer pretrained on sampled KG subgraphs with three self-supervised tasks, reused through triple prompt tuning for triple classification, zero-shot image classification and CommonsenseQA (WWW 2023). (neocortex: skip · LLM: none)
* [Visual In-Context Learning for Large Vision-Language Models](visual-icl-large-vision-language-models.md) - VICL: retrieve demonstration images (retrieve and rerank), summarise them by task intent and compose text demonstrations to cut tokens for LVLMs (ACL Findings 2024). (neocortex: skip · LLM: both)
* [What Makes Good Examples for Visual In-Context Learning?](what-makes-good-visual-icl-examples.md) - Shows that visual in-context learning is sensitive to the choice of demonstrations and proposes prompt retrieval methods to select them. (neocortex: skip · LLM: none)
* [When Do Program-of-Thoughts Work for Reasoning?](when-do-program-of-thoughts-work.md) - Proposes the complexity-impacted reasoning score (CIRS) that ties the structure and logic of code data to whether program-of-thought prompting helps. (neocortex: skip · LLM: none)
