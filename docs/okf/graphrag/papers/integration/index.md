# Knowledge integration (fine-tuning, in-context learning)

* [KnowledGPT: Enhancing Large Language Models with Retrieval and Storage Access on Knowledge Bases](knowgpt.md) - Program-based retrieval over public KBs plus a personalized KB that the LLM fills from documents; not the same work as KnowGPT (arXiv 2312.06185). (neocortex: adapt · LLM: both)
* [Mitigating Large Language Model Hallucinations via Autonomous Knowledge Graph-based Retrofitting](kg-retrofitting-hallucination.md) - KGR checks an LLM draft's claims against KG facts, selects and verifies them, and retrofits the draft during reasoning. (neocortex: adapt · LLM: both)
* [Plan-on-Graph: Self-Correcting Adaptive Planning of Large Language Model on Knowledge Graphs](plan-on-graph.md) - PoG decomposes a question into sub-objectives, explores KG paths adaptively, updates memory, and self-corrects by reflection. (neocortex: adapt · LLM: both)
* [Reasoning on Graphs: Faithful and Interpretable Large Language Model Reasoning](reasoning-on-graphs.md) - RoG plans relation paths with an LLM, then retrieves faithful reasoning paths from the KG and answers from them. (neocortex: adapt · LLM: retrieval)
* [Think-on-Graph 2.0: Deep and Faithful Large Language Model Reasoning with Knowledge-guided Retrieval Augmented Generation](think-on-graph-2.md) - Training-free hybrid RAG that iterates between text passages and a KG, linking documents through entities, in a tight-coupling loop. (neocortex: adapt · LLM: both)
* [Think-on-Graph: Deep and Responsible Reasoning of Large Language Model on Knowledge Graph](think-on-graph.md) - LLM-guided beam search over a KG: the LLM explores relations and prunes candidate triples at each hop, with depth D and width N. (neocortex: adapt · LLM: retrieval)
* [CogMG: Collaborative Augmentation Between Large Language Model and Knowledge Graph](cogmg.md) - Collaborative augmentation in which an LLM and a KG refine each other (ACL 2024 demo, per README). (neocortex: watch · LLM: both)
* [Different Paths to the Same Destination: Diversifying LLMs Generation for Multi-hop Open-domain Question Answering](diversifying-llm-multihop-paths.md) - Diversifies LLM generation of reasoning paths for multi-hop open-domain QA (KBS 2025, per README). (neocortex: watch · LLM: both)
* [Dual Reasoning: A GNN-LLM Collaborative Framework for Knowledge Graph Question Answering](explore-then-determine.md) - Dual-process framework pairing a GNN-based external reasoner on the KG with an LLM. Listed in the README as Explore then Determine. (neocortex: watch · LLM: both)
* [Graph Chain-of-Thought: Augmenting Large Language Models by Reasoning on Graphs](graph-chain-of-thought.md) - Graph-CoT lets an LLM reason step by step over a text-attributed graph, with the graph as the knowledge source. (neocortex: watch · LLM: both)
* [Graph Neural Prompting with Large Language Models](graph-neural-prompting.md) - Plug-and-play graph neural prompting that feeds KG knowledge into a frozen pretrained LLM. (neocortex: watch · LLM: indexing)
* [GraphGPT: Graph Instruction Tuning for Large Language Models](graphgpt.md) - Graph-oriented LLM that aims at zero-shot generalization across graph datasets and tasks through graph instruction tuning. (neocortex: watch · LLM: indexing)
* [Knowledge Graph-Enhanced Large Language Models via Path Selection](kg-enhanced-llm-path-selection.md) - KELP scores KG paths against the input text by latent semantic matching, then feeds the selected paths to the LLM (ACL Findings 2024). (neocortex: watch · LLM: both)
* [Language is All a Graph Needs](language-is-all-a-graph-needs.md) - Casts graph problems as text so a generative language model can solve them within one framework. (neocortex: watch · LLM: indexing)
* [LLaGA: Large Language and Graph Assistant](llaga.md) - Adapts graph neighborhoods into an LLM-compatible input format so a general LLM can work on graph data. (neocortex: watch · LLM: indexing)
* [MuseGraph: Graph-oriented Instruction Tuning of Large Language Models for Generic Graph Mining](musegraph.md) - One foundation model that combines GNN and LLM strengths to handle diverse graph mining tasks and datasets. (neocortex: watch · LLM: indexing)
* [An Explanation of In-context Learning as Implicit Bayesian Inference](icl-implicit-bayesian-inference.md) - Theory that in-context learning emerges from implicit Bayesian inference when pretraining documents have long-range coherence. (neocortex: skip · LLM: none)
* [Chain-of-Knowledge: Grounding Large Language Models via Dynamic Knowledge Adapting over Heterogeneous Sources](chain-of-knowledge.md) - Prepares rationales, then adapts them step by step with grounding from heterogeneous knowledge sources when answers disagree. (neocortex: skip · LLM: both)
* [Exploring Large Language Model for Graph Data Understanding in Online Job Recommendations](job-recommendation-llm-graph-understanding.md) - Fine-tunes an LLM on path-level graph data for job recommendation (AAAI 2024, per README). (neocortex: skip · LLM: indexing)
* [GraphWiz: An Instruction-Following Language Model for Graph Problems](graphwiz.md) - An open instruction-tuned LLM for graph problems, trained on explicit reasoning-path data (GraphInstruct). (neocortex: skip · LLM: indexing)
* [Large Language Models based Graph Convolution for Text-Attributed Networks?](llm-graph-convolution-text-attributed-networks.md) - Question whether LLM-based graph convolution suits text-attributed networks (OpenReview, README entry). (neocortex: skip · LLM: indexing)
* [Plan-and-Solve Prompting: Improving Zero-Shot Chain-of-Thought Reasoning by Large Language Models](plan-and-solve-prompting.md) - Zero-shot prompting that plans first and then solves, aimed at calculation, missing-step and semantic errors. (neocortex: skip · LLM: both)
* [RHO: Reducing Hallucination in Open-domain Dialogues with Knowledge Grounding](rho-hallucination-dialogue.md) - Grounds dialogue responses on representations of KG entities and relation predicates to reduce hallucination. (neocortex: skip · LLM: both)
* [Structure Pretraining and Prompt Tuning for Knowledge Graph Transfer](kg-transfer-structure-pretraining-prompt-tuning.md) - Pretrains on KG structure and transfers it via prompt tuning (WWW 2023, per README). (neocortex: skip · LLM: indexing)
* [Visual In-Context Learning for Large Vision-Language Models](visual-icl-large-vision-language-models.md) - Visual in-context learning for LVLMs: retrieve demonstration images, summarize them by intent, and compose language demonstrations. (neocortex: skip · LLM: both)
* [What Makes Good Examples for Visual In-Context Learning?](what-makes-good-visual-icl-examples.md) - Investigates what makes demonstrations effective for in-context learning in large vision models. (neocortex: skip · LLM: both)
* [When Do Program-of-Thoughts Work for Reasoning?](when-do-program-of-thoughts-work.md) - Proposes CIRS, a score combining structural and logical code attributes, to measure how code data affects reasoning. (neocortex: skip · LLM: both)
