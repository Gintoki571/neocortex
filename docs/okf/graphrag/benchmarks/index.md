# Benchmarks

* [GraphRAG-Bench](graphrag-bench.md) - Benchmark of about 4,000 questions over two corpora (Gutenberg novels and medical guidelines) asking when graph structure helps RAG across four task levels. (neocortex: adopt · LLM: both)
* [MetaQA](metaqa.md) - Multi-hop KB question answering benchmark (1-, 2- and 3-hop) built on WikiMovies, with NTM-paraphrased and audio variants; over 400K questions in total. (neocortex: adopt · LLM: none)
* [MetaQA-3 (3-hop split)](metaqa-3hop.md) - The 3-hop split of MetaQA: 142,744 template questions over the WikiMovies KB, requiring three-hop logical reasoning. (neocortex: adopt · LLM: none)
* [MultiHop-RAG](multihop-rag.md) - RAG benchmark of 2,556 multi-hop news queries with gold evidence sentences, ground-truth answers and null (unanswerable) queries. (neocortex: adopt · LLM: both)
* [ComplexWebQuestions (CWQ)](cwq.md) - 34,689 complex questions over Freebase, generated by composing SPARQL queries from WebQuestionsSP with conjunctions, superlatives, comparatives and compositions. (neocortex: adapt · LLM: none)
* [DIGIMON (graph RAG unified-framework benchmark)](digimon.md) - Study that places graph-based RAG methods in one framework and compares them on 11 QA datasets, from specific to abstract questions. (neocortex: adapt · LLM: both)
* [KQA Pro](kqa-pro.md) - About 118K natural-language complex KBQA questions with KoPL programs and SPARQL queries, for diagnosing compositional reasoning skills. (neocortex: adapt · LLM: none)
* [PolyBench (PolyG benchmark)](polyg.md) - GraphRAG benchmark of 1,200 knowledge-graph questions built from a four-class question taxonomy, plus the PolyG adaptive method. (neocortex: adapt · LLM: retrieval)
* [CRUD-RAG](crud-rag.md) - Chinese RAG benchmark with four application types (Create, Read, Update, Delete) that evaluates every RAG component. (neocortex: watch · LLM: both)
* [FACTKG](factkg.md) - Fact-checking dataset over a knowledge graph (ACL 2023). (neocortex: watch · LLM: none)
* [GrailQA](grailqa.md) - Large-scale KBQA dataset with 64,331 questions and three levels of generalization (i.i.d., compositional, zero-shot). (neocortex: watch · LLM: none)
* [LC-QuAD](lc-quad.md) - Large-scale complex question answering dataset (ISWC 2017). (neocortex: watch · LLM: none)
* [LC-QuAD 2.0](lc-quad-2.md) - Large-scale complex question answering benchmark (ISWC 2019) with a figshare release. (neocortex: watch · LLM: none)
* [Mintaka](mintaka.md) - End-to-end multilingual complex QA dataset with 20,000 English question-answer pairs, annotated with Wikidata entities. (neocortex: watch · LLM: none)
* [TutorQA](tutorqa.md) - Domain-specific QA benchmark listed in the README with an arXiv 2407.10794 link. (neocortex: watch · LLM: both)
* [UltraDomain](ultradomain.md) - Domain-specific long-context QA dataset, introduced with MemoRAG (the dataset link in the README points to the MemoRAG repo). (neocortex: watch · LLM: both)
* [SimpleQuestions](simplequestions.md) - Large single-relation question-answering dataset of 100k questions over a knowledge base, used with Memory Networks. (neocortex: skip · LLM: none)
* [WebQSP](webqsp.md) - WebQuestionsSP: semantic parse labels for WebQuestions over Freebase (ACL 2016). (neocortex: skip · LLM: none)
* [WebQuestions (WebQ)](webq.md) - Question-answering benchmark over Freebase, cited in the README for simple QA. (neocortex: skip · LLM: none)
