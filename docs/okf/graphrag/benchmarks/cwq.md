# Summary
- The dataset contains 34,689 question-answer pairs, with SPARQL queries and web snippets released alongside; the SPARQL is not used by the authors' model.[^pdf]
- Construction: the 4,737 WebQuestionsSP questions and their SPARQL were extended into four complex types (conjunctions, superlatives, comparatives, compositions); questions were then paraphrased by Amazon Mechanical Turk workers (200 workers in total).[^pdf]
- Answers are computed by executing the SPARQL against Freebase.[^pdf]

# Method
- The paper's method decomposes each question into simpler questions, retrieves answers from the web as a knowledge base, and recomposes them with set operations.[^pdf]
- Training uses noisy supervision from question-computation tree pairs or question-answer pairs.[^pdf]

# Results
- Question decomposition raises precision@1 on ComplexWebQuestions from 20.8 to 27.9 in the paper's experiments.[^pdf]

# Relevance to neocortex
- Offline scoring is exact: the gold SPARQL gives the answer set. The blocker is the knowledge base: Freebase is large, so a neocortex run would need a subset loaded as relation facts. Only then can the conjunction and composition types be scored.[^pdf]
- Its compositional types are the closest public match to neocortex's set-style gaps; use the paper's 34,689 pairs and pick a subset that fits in memory.
